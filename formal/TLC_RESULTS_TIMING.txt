#   (NoEffect holds). Client-local evidence: an identity first sent after t0 + e + eps cannot take effect.
# firstsend_before_expiry_witness: a first send <= t0 + e (0..3): TLC finds a behaviour in which the identity takes
#   effect and the client receives no answer (the reply is lost): its view (the same sends, no answer) is the one of
#   the behaviour in which every copy is lost. This is the indistinguishable execution of Theorem 2(b).
# firstsend_boundary_witness: a first send at exactly t0 + e + eps (4): still a witness, with the owner's clock eps behind
#   and no delay; with the first case, the boundary is t0 + e + eps exactly.
# original_after_validity: the dispatcher's rule (internal/outbox/dispatcher.go; RetryAllowedUntilFunc allows attempt 0

# reissue_after_validity: the original obeys V - D, STOPPED evidence, a re-issue created while now + D <= V and queued;
#   its original (attempt 0 of a new identity) leaves after V - D and takes effect late.
# validity_every_attempt: every attempt (originals, resends, the queued re-issue) leaves only while now + D <= V, and an
